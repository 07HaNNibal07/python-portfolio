# Портфолио Ильгара

Статический сайт на HTML, CSS и обычном JavaScript. Без сборки, npm, сторонних библиотек, внешних шрифтов и backend. Все ресурсы локальные.

## Запуск

Самый простой способ — открыть `index.html` двойным щелчком. Сайт не использует `fetch` или модули, поэтому работает и с `file://`.

Для локального HTTP-предпросмотра откройте PowerShell в папке сайта и выполните:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000. Остановить сервер — `Ctrl+C`. Если команда `python` недоступна, попробуйте `py -m http.server 8000 --bind 127.0.0.1`.

## Добавить проект

В массиве `projects` в `content.js` скопируйте один объект. Задайте уникальный `id`, название, описание, стек, ссылку и списки возможностей. `cover` может быть `cinema`, `fitness` или `career`. Количество проектов в кнопке «Все проекты» обновляется автоматически.

Для нового фреймворка добавьте кнопку фильтра в HTML с `data-filter`, равным полю `framework` проекта. Карточки остаются работоспособными без нового фильтра: они видны в «Все проекты».

## Скриншоты и видео

Скопируйте файлы в `assets/` и заполните поля нужного проекта в `content.js`:

```javascript
screenshot: 'assets/cinema-screen.webp',
screenshotAlt: 'Страница выбора сеанса в CinemaProject',
video: 'assets/cinema-demo.mp4'
```

Поддерживается основной скриншот, дополнительные снимки и одно MP4-видео на проект. Подпись основного снимка задаётся полем `screenshotCaption`. Дополнительные снимки добавляются в `extraScreenshots`: `[{ src: 'assets/another-screen.jpg', alt: 'Описание экрана', caption: 'Подпись' }]`. По нажатию снимок открывается в полном размере. Пустые поля оставляют подписанное место под медиа. Не указывайте несуществующие файлы.

В `assets/screenshots/` добавлены шесть реальных снимков локально запущенных копий проектов. На экранах используются демонстрационные данные. У диплома снят Swagger UI; готовый пользовательский интерфейс не подразумевается. Результаты проверок и найденные ошибки описаны в `PROJECT_TEST_REPORT.md`.

В BosnaFitClub уже добавлена копия `Запись 2026-06-24 220355.mp4` из исходной папки под именем `assets/bosnafitclub-demo.mp4` (около 21,5 МБ). Видео загружается только после открытия подробностей проекта, автоматического воспроизведения нет. Другие медиа не переносились. Графические обложки карточек — иллюстрации, не скриншоты приложений.

## Интерактивность и доступность

Фильтры FastAPI/Django; модальные описания; адаптивное меню; плавная прокрутка и появление секций. Диалог закрывается крестиком, Escape или нажатием за его пределами, возвращает фокус кнопке открытия и останавливает видео. Системная настройка уменьшения движения отключает анимации. Использованы семантические разделы, видимый фокус и ссылка пропуска навигации.

Без JavaScript доступны основные разделы и прямые ссылки в `noscript`; интерактивные карточки требуют JavaScript.

## Размещение

Папка готова для любого статического хостинга, включая GitHub Pages. Публикация в ходе этой задачи не выполнялась. Перед публикацией просмотрите демонстрационную запись и при необходимости замените её. Для сайта не нужны исходные папки Python-проектов, `.env`, базы данных или виртуальные окружения.
